# 财务智能识别与中转站配置

## 功能边界

财务月度归集页面的“智能识别归集”会读取当前任务尚未归集的有效文件，使用已经建立的正文索引和文件元数据，生成：

- 材料类型：报销单、发票、付款单、车票/行程单、合同、银行回单、其他凭证
- 报销人、日期、金额、商户、项目、事项关键词
- 建议的事项目录和导出文件名

识别结果只会保存为草稿建议。用户可以修改目录、材料类型和导出文件名，也可以选择“暂不处理”；点击“确认并归集”后才会创建归集目录和归集条目。原文件、正式分类、标签、历史版本和存储位置不会被 AI 修改。

## OpenAI 兼容中转站

后端通过 OpenAI Chat Completions 兼容协议调用中转站，不把 Key 放入前端。推荐管理员登录桌面端后，从左侧“AI 接口配置”填写并保存。配置页面支持获取中转站实际提供的模型列表、测试连接，保存后立即生效。

推荐操作顺序：

1. 填写中转站基础地址、API Key，打开“启用财务智能识别”，填写任意模型名称后点击“保存配置”。
2. 点击“获取模型列表”，系统会读取中转站兼容 OpenAI 的 `GET /models` 响应，并在模型名称输入框中提供可搜索的下拉选项。列表中可以出现中转站实际返回的 `gpt-5.5`、`gpt-5.6-luna`、`gpt-5.6-sol` 等具体版本；中转站没有提供列表接口时仍可手动填写模型名称。
3. 选择实际模型并再次保存，然后点击“保存并测试连接”。页面会固定显示“已连接”或“连接失败”、测试时间、模型、验证接口和耗时；保存新配置后，旧测试结果会清除，避免误把旧配置显示为已连接。也可以先保存，再点击“重新测试”。

“已配置”只表示参数完整，不代表已经连通。只有“API 已连接”或顶部“已连接”才表示最近一次测试请求成功。测试失败会显示安全的原因摘要，不会显示 API Key 或中转站完整响应。

首次部署或无法打开页面时，也可以编辑项目根目录的 `.env.production`：

```env
FINANCE_AI_ENABLED=true
OPENAI_API_KEY=你的中转站API_KEY
OPENAI_BASE_URL=https://你的中转站地址/v1
OPENAI_MODEL=你的模型名称
FINANCE_AI_TIMEOUT_MS=60000
FINANCE_AI_MAX_OUTPUT_TOKENS=1800
FINANCE_AI_MAX_DOCUMENTS=500
FINANCE_AI_MAX_INPUT_CHARS=12000
```

`OPENAI_BASE_URL` 填到 `/v1`，不要填写完整的 `/chat/completions`；程序会自动拼接接口路径。如果中转站要求其他模型名称，使用中转站实际提供的名称。

配置完成后，在项目目录运行：

```powershell
docker compose --env-file .env.production -f docker-compose.prod.yml up -d
```

登录系统后，打开“财务月度归集”，点击“智能识别归集”。识别任务会显示处理进度；完成后必须人工确认。

通过桌面端保存的数据库配置优先于 `.env.production`。如果数据库中已经保存过配置，之后修改 `.env.production` 不会覆盖页面配置；应直接在“AI 接口配置”中修改，或清除数据库配置后再使用环境变量回退。

## 关闭方式

管理员可以在“AI 接口配置”中关闭开关，保存后立即生效。也可以将 `FINANCE_AI_ENABLED=false`，再重启后端容器：

```powershell
docker compose --env-file .env.production -f docker-compose.prod.yml up -d --force-recreate backend
```

关闭后不会再向外部模型发送内容，已有的正文索引、文件和已确认的归集结果不受影响。

## 数据与隐私

启用后，后端可能向中转站发送每个文件的标题、原文件名、分类、部门、标签、上传时间和最多 `FINANCE_AI_MAX_INPUT_CHARS` 个正文字符。API Key 只存在于后端环境变量和后端请求头中，日志不会记录 Key 或完整模型回复。

在使用真实财务资料前，应确认中转站的数据保留、训练使用、传输加密和合规条款。无法接受外发文件正文时保持关闭，继续使用本地关键词和正文索引检索。

## 接口

| 方法 | 路径 | 用途 |
|---|---|---|
| `GET` | `/api/finance-packages/ai/status` | 查看开关、模型和配置状态，不返回 Key |
| `GET` | `/api/finance-packages/ai/config` | 管理员查看配置和最近一次连接测试结果，不返回 Key |
| `GET` | `/api/finance-packages/ai/config/models` | 管理员读取中转站可用模型 ID，不返回完整外部响应 |
| `PATCH` | `/api/finance-packages/ai/config` | 管理员保存中转站配置 |
| `POST` | `/api/finance-packages/ai/config/test` | 管理员测试中转站连接并记录结果 |
| `POST` | `/api/finance-packages/ai/config/verify` | 管理员验证当前保存的 Key、模型和中转站连通性 |
| `POST` | `/api/finance-packages/:id/analysis` | 创建异步识别任务，可传 `documentIds` 分批处理 |
| `GET` | `/api/finance-packages/:id/analysis/:jobId` | 查询进度和待确认建议 |
| `POST` | `/api/finance-packages/:id/analysis/:jobId/confirm` | 人工确认、修改并写入归集任务 |

`documentIds` 最多一次传 500 个，默认只分析当前任务中尚未归集的有效文件。重复启动同一任务会被拒绝，避免并发重复调用。

如果中转站不支持 `GET /models`，模型列表按钮会明确提示，仍可手动填写模型名称；“保存并测试连接”会直接通过 `chat/completions` 验证该模型是否可用。
