## 2. 结论摘要

除以下两项按要求暂缓外，其余已确定功能均已实现并完成代码、构建或运行验证：

1. 暂不在生产环境配置有效的 AI/Embedding API Key。
2. 暂不启用语义向量检索，也暂不重建向量索引。

因此当前系统可以稳定使用普通关键词、模糊关键词和已解析正文检索；检索助手在没有有效 API Key 时自动使用关键词模式，不影响文件上传、分类、查看、下载、更新、删除、恢复、导出和打印等核心业务。

## 4. AI 检索验收边界

本次明确暂缓的不是普通检索功能，而是语义增强部分：

| 项目 | 当前状态 |
|---|---|
| AI/Embedding API Key | 未配置有效 Key，按要求暂缓 |
| `AI_SEARCH_ENABLED` | 当前关闭，系统使用关键词模式 |
| 语义向量 | 当前有效向量数为 0，按要求暂不生成 |
| 向量索引重建 | 已提供管理员接口 `POST /api/search/index/rebuild`，但本次不执行 |
| 检索助手 | 已可用；无有效 Key 时返回关键词检索结果 |

这意味着当前检索助手可以处理明确的文件名、编号、分类、标签和正文关键词；“使用语义理解查找未包含原词但意思相近的文件”需要以后配置 API Key 并重建索引后才会生效。

## 7. 当前运行状态

验收命令执行时：

- `docker compose -f docker-compose.prod.yml ps` 显示没有运行中的容器。
- 这不表示 Docker 配置失败，而是当前服务处于停止状态。
- 需要使用项目内的启动脚本或 Compose 命令启动后，Web 端和桌面端才能连接到后端。
- 生产配置已取消后端直接端口发布，后端应由前端容器内部访问；旧镜像层可能仍显示 `EXPOSE 3000`，不会影响前端使用，后续重建镜像即可消除显示残留。
