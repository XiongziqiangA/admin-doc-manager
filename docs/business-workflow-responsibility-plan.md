# 项目与事项责任闭环实施计划

## 目标

让每个事项都能明确回答：谁负责、当前状态、下一步动作、截止时间、谁审批、谁付款、谁完成，以及发生过哪些变化。

## 阶段一：责任基础版

- 跟进任务增加进度、完成说明、取消原因、开始时间、完成/取消人员。
- 借款与报销增加申请人、经办负责人、审批人、付款人、结算负责人。
- 服务端限制财务状态流转，并记录审批、付款、结算人员和时间。
- 任务完成和取消需要责任人或管理员操作，并保留结果说明。
- 工作台增加按“我的任务”和“未分配任务”查看的能力。

验收：创建任务或财务记录后可看到责任人；非法状态跳转被拒绝；完成、审批、付款、结算都有人员和时间；旧数据仍可读取。

## 阶段二：过程跟进版

- 新增人工跟进记录，支持跟进方式、结果、下一步动作、下一位责任人和下次跟进日期。
- 事项详情展示责任摘要、逾期任务、待处理财务记录和最近一次跟进。
- 工作台展示待跟进和逾期风险。

验收：一条跟进记录可以完整描述一次业务推进，并能形成下一次责任提醒。

## 阶段三：审计统计版

- 操作记录保留修改前后差异和状态变化。
- 责任人变更可追溯。
- 按员工统计任务、借款、报销、逾期和待办。
- 支持按期间导出责任报表。

验收：管理员可以按人员和期间查看责任数据，并导出可交付的 CSV 报表；普通用户不能修改或删除审计记录。
