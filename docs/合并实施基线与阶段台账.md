## 不可破坏的行政功能

每个阶段都必须回归以下能力：

- 登录和管理员/员工账号。
- 文件单个上传、批量上传和桌面拖放上传。
- OFD、PDF、Office、图片、压缩包等办公格式选择。
- 重复文件名提示和上传新版本。
- 文件分类、树形子分类、标签和移动分类。
- 文件详情、预览/打开、下载、打印、版本历史。

## UI 目标

最终 UI 采用此前确认的统一企业工作台风格：深色左侧导航、顶部全局搜索、文件/资产/待办/财务指标、重点项目与资产状态、最近文件和待办提醒。该设计只调整信息架构和视觉呈现，不删减任何现有行政功能；原功能会归入对应一级模块或详情页签。

- 自动化测试共 31 个文件、164 项通过；全工作区类型检查和后端、前端、桌面端构建通过。
