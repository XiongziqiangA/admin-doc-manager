## UI 目标

最终 UI 采用此前确认的统一企业工作台风格：深色左侧导航、顶部全局搜索、文件/资产/待办/财务指标、重点项目与资产状态、最近文件和待办提醒。该设计只调整信息架构和视觉呈现，不删减任何现有行政功能；原功能会归入对应一级模块或详情页签。
