# 项目与事项中心第二、第三阶段实施方案

## 1. 阶段目标

第一阶段已经完成事项中心、事项上下级关系和文件关联。本方案继续把“事项”从一个文件关联容器扩展为可跟进、可记录、可提醒的业务工作台。

设计原则：

- 不改变文件中心的分类、标签、版本、回收站和真实存储方式。
- 不把借款、报销和合同字段继续堆入 `Document` 或第一阶段事项主表。
- 所有新业务数据都以事项为归属，文件通过关联关系复用，不复制源文件。
- 员工只能维护自己创建或负责的事项及其业务记录，管理员可以维护全部事项。
- 第一阶段不引入审批流、完整会计核算或自动改变正式分类的 AI 行为。

## 2. 第二阶段：业务闭环

### 2.1 跟进任务

在事项下维护日常行政跟进事项：

- 任务标题、说明、负责人、优先级、状态、截止日期。
- 支持待处理、进行中、已完成、已取消。
- 支持编辑、完成、删除和按状态筛选。
- 截止日期保留原始时间，后续可用于逾期和即将到期概览。

### 2.2 合同资料

合同类事项可以维护一份独立合同信息：

- 合同编号、签约方、签署日期、生效日期、到期日期。
- 金额、续签提醒提前天数、合同状态和备注。
- 合同信息与事项下的合同文件互相独立，删除合同信息不会删除文件。

### 2.3 借款与报销记录

事项下新增财务业务记录：

- 记录类型：借款、报销。
- 单号、标题、金额、币种、发生日期、往来对象、状态、结算日期和备注。
- 借款状态和报销状态采用同一套可扩展状态：草稿、待处理、已批准、已支付、已结清、已拒绝、已取消。
- 财务记录可以批量关联已有文件作为凭证，仍然不复制或移动源文件。

## 3. 第三阶段：协同与运营

### 3.1 工作台概览

提供当前登录用户可见的：

- 事项总数、进行中事项数。
- 待办任务数、逾期任务数、7 天内到期任务数。
- 即将到期合同数。
- 借款和报销记录金额汇总。

### 3.2 到期提醒数据

系统提供可重复查询的提醒列表，不主动发送邮件或短信：

- 逾期任务。
- 7 天内到期任务。
- 续签提醒窗口内的合同。

提醒只读展示，业务人员仍在任务或合同详情中处理实际内容。

### 3.3 业务日志

记录事项业务层的创建、修改、完成、删除、关联凭证等操作，至少包含操作人、动作、摘要和时间。

## 4. API 契约

所有接口都继承现有 JWT 和事项权限边界：

```text
GET    /api/business-matters/:matterId/tasks
POST   /api/business-matters/:matterId/tasks
PATCH  /api/business-matters/:matterId/tasks/:taskId
DELETE /api/business-matters/:matterId/tasks/:taskId

GET    /api/business-matters/:matterId/contract
PUT    /api/business-matters/:matterId/contract
DELETE /api/business-matters/:matterId/contract

GET    /api/business-matters/:matterId/finance-records
POST   /api/business-matters/:matterId/finance-records
PATCH  /api/business-matters/:matterId/finance-records/:recordId
DELETE /api/business-matters/:matterId/finance-records/:recordId
POST   /api/business-matters/:matterId/finance-records/:recordId/documents
DELETE /api/business-matters/:matterId/finance-records/:recordId/documents/:documentId

GET    /api/business-workflow/overview
GET    /api/business-workflow/reminders
GET    /api/business-matters/:matterId/activities
```

## 5. 验收标准

### 第二阶段

1. 可以在事项详情创建、编辑、完成和删除跟进任务。
2. 任务负责人、权限、截止日期和状态在服务端校验。
3. 合同事项可以保存合同信息，日期倒置和非法提醒天数被拒绝。
4. 借款和报销记录可以新增、修改、变更状态和删除。
5. 财务记录可以关联已有文件，重复关联和已删除文件被拒绝。
6. 删除任务、合同信息或财务记录不会删除文件中心文件和文件版本。

### 第三阶段

1. 工作台概览返回事项、任务、合同和财务金额统计。
2. 逾期、7 天内到期任务和合同提醒可以按用户权限查询。
3. 关键业务操作可以在事项活动列表中看到操作人、动作和时间。
4. 前端事项详情可以直接维护上述业务数据，不需要左右滚动。
5. 原有上传、分类、版本、回收站、搜索、财务归集和 AI 配置功能回归通过。
6. 全部后端测试、类型检查、生产构建、Docker 健康检查和真实 API 烟测通过。

## 6. 明确不纳入本次

- 多企业租户隔离。
- 审批流和电子签章。
- 完整会计科目、自动记账和税务申报。
- 自动邮件、短信或企业微信推送。
- AI 自动确认业务关系。
